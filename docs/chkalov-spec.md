## 4. Инициализация

### 4.1. Значения по умолчанию

Если переменная объявлена без явного инициализатора, она
инициализируется **значением по умолчанию** своего типа:

| Тип      | Значение по умолчанию |
|----------|-----------------------|
| Int      | 0                     |
| Long     | 0                     |
| Char     | 0                     |
| Short    | 0                     |
| UInt     | 0                     |
| ULong    | 0                     |
| UChar    | 0                     |
| UShort   | 0                     |
| String   | "" (пустая строка)    |
| Void     | (нет значения)        |

### 4.2. Когда происходит инициализация

- **Локальные переменные**: инициализируются в точке объявления.
- **Глобальные переменные**: инициализируются при запуске программы (до `main`).
- **Аргументы функций**: инициализируются из места вызова.
- **Возвращаемые значения**: инициализируются оператором `return`.

### 4.3. Явная инициализация

Переменная не может быть явно инициализирована при объявлении (следующие примеры кода являются ошибочными):

    var Int: x = 42
    var String: s = "Hello, World!"

### 4.4. Неинициализированные переменные

Если переменная объявлена без инициализатора, она инициализируется
значением по умолчанию своего типа (см. 4.1). Чтение
неинициализированной переменной **не** является неопределённым
поведением (UB) — оно всегда возвращает значение по умолчанию.
