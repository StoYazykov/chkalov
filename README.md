# Язык программирования Чкалов

# Преимущества:  

## 1. Высокая скорость компиляции.  

Для примера, напишем программу Hello World! на двух ЯП: Чкалов и Kotlin.  
**Kotlin:**  
`fun main() {  
println("Hello World!")  
}`  
**Чкалов:**  
`@println("Hello World!")`  
  

### Время компиляции (ЦПУ AMD A8 с тактовой частотой 1.6 - 2.0 ГГц, 16 ГБ ОЗУ, SSD, Debian GNU/Linux 12:  

**Kotlin:**  
Компиляция: real 13,838s, user 28,178s.  
Выполнение в JVM: real 0,420s, user 0,355s.  
  

**Чкалов:**  
Компиляция: real 0,008s, user 0,001s.  
Выполнение в CVM: real 0,008s, user 0,004s.
**Разница в скорости - 1730 раз при компиляции и в 52 раза при выполнении!**


## 2. Малый размер байт-кода:  

**Kotlin: 621 байт.**
**Чкалов: 74 байта.**

**Выигрыш в размере - 8.4 раза!**

## 3. Минималистичный рантайм
Вся виртуальная машина Чкалова занимает 209 КБ. 
JVM занимает сотни мегабайт. 
**Чкалов запускается мгновенно и не требует установки Java/Kotlin runtime.**
